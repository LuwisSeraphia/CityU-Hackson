# 最小路演路线

## 启动

真实 Codex 模型（使用本机已登录 CLI，不复制凭据，保留百炼接口）：

```bash
conda activate hackson-cityu
python scripts/dev_local.py --codex-cli --port 5177 --api-port 8003 --data-dir apps/api/.data/codex-public-demo
```

仅使用公开示例；演示页的消息、该页历史和勾选的资料会发送给 Codex 模型服务。该模式不提供向量生成或自动联网搜索，资料通过后端关键词检索与文件工具引用。CLI 模式不是 API Key，百炼仍通过 `--cloud` 和 apps/api/.env 接入。

离线备用（固定规则模板，页面明确标注非云 AI）：

```bash
python scripts/dev_local.py --demo --port 5176 --api-port 8002 --data-dir apps/api/.data/roadshow
```

## 90 秒最小展示

1. 知识书墙：展示泡泡与图书馆，打开“一片叶子的能量旅行”。
2. 新建对话，勾选“附上本地书墙相关资料”，输入“光合作用是什么？请根据所附资料用两句话回答，并引用来源。”
3. 等待回答，点击“查看来源 1”，展示真实原文。
4. 刷新，点击侧栏历史，确认答案仍存在。

CLI 服务不可用时，手动切换离线页并明确说明使用固定模板，不能将备用模板称为真实模型回答。

## 已有与边界

- 聊天、引用、历史、取消、重试、技能表单：已接后端。
- 知识来源：内置示例；知识墙手动录入；导入 TXT / Markdown；手动粘贴知乎正文。单个导入文件限制 400KB，资料正文最多 10 万字符。
- 知乎网址仅是书签，不自动抓取；勾选附带资料后才上传命中节选。
- 技能中的流程规划与归档是方案生成，不会操作用户磁盘。CLI 模式使用真实模型，离线模式使用明确标注的固定模板。
- 文稿、图片、此电脑是用户选择文件后的本地预览，未做云同步；“设置”不是账号登录。
- 定时任务只在页面打开时触发；“立即交代”和到点触发已接聊天后端，不是关闭页面后仍工作的后台调度。
- Token 看板仍是界面估算，不能作为真实账单。
- AI 分类需要真实模型；离线模式请使用本地分类建议。
- 服务重启后，遗留运行会结束为可重试状态，避免永久显示处理中。
- 三项历史文档测试依赖缺失的 docs/memory-retrieval-observability-prd.md，功能测试单独执行；没有伪造该文档来让检查通过。

## 本轮实测

Codex CLI 最小请求返回 CITYU_MODEL_OK；网页公开资料问答成功返回光合作用解释和来源按钮。另有前端测试、构建、后端测试和 HTTP 链路验收。真实百炼 / PostgreSQL 本轮未配置验收，不应展示为已跑通。
