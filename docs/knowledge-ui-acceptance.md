## 人工验收建议

1. 在原来使用的地址打开项目，点击知识书墙，确认侧栏保留，右侧成为知识页面。
2. 添加几份不同长度和分区的知识，切换灵感 / 图书馆；点击泡泡、卡片查看详情。
3. 查看分区筛选、关键词搜索；编辑标题、正文和标签，刷新后确认保留。
4. 管理分区：新增、重命名；删除有资料的分区后确认资料仍在待整理。
5. 返回办公室，反复收起 / 展开工作概览，确认画布不变形、角色仍可点击。
6. 从知识页进入新对话或历史对话，再返回办公室，确认没有残留页面遮挡。
7. AI 分区按本地启动文档配置后端后验收；未配置时应显示明确错误，不报告识别成功。

测试预览地址使用 127.0.0.1:5174，内有手动添加的示例笔记。浏览器按来源隔离存储；原地址 / 端口的资料不会出现在该预览中，也未被修改。

## 第二轮交互调整

- 灵感模式取消网格，泡泡随机位置与大小，持续独立运动、缓慢转向、边缘回弹及轻微避让。鼠标或键盘聚焦的单个泡泡停下，其余继续移动。
- 灵感模式隐藏分区导航；底部白色圆角搜索框固定在视口中，滚动时不移动。图书馆保留分区和顶部搜索。
- “应用”替换为可悬停或点击展开的弧形工具栏，五个图标分别进入知识书墙、技能工具箱、新建对话、自动任务和设置。
- 文稿、图片和此电脑收进三点“更多”菜单。
- 工具栏支持方向键、Home / End、Enter、Escape；关闭工具栏时不退出知识页。
- 前端测试、构建、语法检查通过。新增泡泡运动测试模拟 30 秒，检查随机大小、独立位置、窄屏 / 宽屏边界和单个泡泡冻结。
- 浏览器验证底部搜索在滚动前后位置一致，工具栏图标能打开对应功能，三点菜单能展开并进入文稿；检查 390px 窄屏布局。

## Application 悬停优化

恢复原版应用中的技能工具箱、本地文档、图片查看器和自动任务，工具定义与原版应用面板共用。上方重复的技能广场 / 自动任务入口已合并到工具栏。

展开与收起改为可反向衔接的淡入 / 淡出和位移动画，图标、文字同时响应悬停；鼠标点击不再固定展开。按钮与弧形区之间保留短暂过渡容错，离开整个区域后收起。

本轮前端测试、生产构建、语法与导入检查通过。浏览器通过实际指针拖移验证纯悬停展开、跨越到工具区不闪退、移出后自动收起，以及文字颜色 / 位移变化；四个工具入口均可打开对应功能。

## 技能直接进入工具栏

工具栏最终收纳网页资料整理、工作流程规划、文件归档方案和定时任务。三个技能直接打开可编辑任务要求，再交给对应伙伴。三点菜单仅保留文稿、图片、此电脑，两处入口不再重复。

本轮语法、前端测试与构建通过；浏览器逐项核对三个技能的任务模板、对应 Agent 和定时任务配置页，四个入口均正常。
