# 知乎 · 刘看山的知识星球办公室

使用原生 JavaScript（ES Modules）、Three.js、HTML、CSS 和 Vite 构建的交互式 2.5D Agent 办公室。

## 环境要求

- Node.js 20.19 或以上，推荐 Node.js 22。
- npm（随 Node.js 安装）。
- 支持 WebGL 2 的 Chrome、Edge 或 Firefox，启用硬件加速。
- 首次安装依赖时需要访问 npm 仓库。

## 完整前后端最小框架

已安装依赖后，在 `hackson-cityu` 环境运行：

```bash
python scripts/dev_local.py --demo
```

启动前端、后端与持久化 SQLite 联调库，不需要模型密钥。页面明确标注“本地联调模式”，回答不是云端 AI。配置百炼与 PostgreSQL 后可使用 `--cloud`。运行、测试和人工验收见 [最小框架说明](docs/minimal-chat-framework.md)。

## 下载并启动

```bash
git clone https://github.com/LuwisSeraphia/CityU-Hackson.git
cd CityU-Hackson
npm install
npm run dev
```

如果已经在本项目目录中，直接从 `npm install` 开始。

浏览器打开终端显示的地址，默认是 **http://localhost:5173**。端口被占用时 Vite 会选择下一个可用端口，请以终端输出为准。停止服务按 `Ctrl+C`。

指定端口：

```bash
npm run dev -- --port 3000
```

## 构建与检查

```bash
npm run check   # JavaScript 语法及相对导入检查
npm test        # 状态、对话存储、模型、拾取、知识检索和走动测试
npm run build   # 生产构建，输出 dist/
npm run preview # 预览生产构建，默认 http://localhost:4173
```

`npm run preview` 前先执行 `npm run build`。部署时将 `dist/` 交给静态网站服务器，不要直接双击 HTML 文件。项目采用相对资源路径，支持静态子目录部署。

## 使用方式

### 办公室

- 左键拖动旋转，右键拖动平移，滚轮缩放。
- 点击 Agent、角色标签或右侧团队成员打开任务面板。
- 输入任务并发送，对应伙伴切换为工作状态；可继续工作、思考、完成或重置。
- 点击任务卡可返回对应伙伴。
- 底部支持动画暂停、变速和视角重置。
- 空闲 Agent 会随机离座、短暂停留后返回；正在工作、思考、被选中或取书的伙伴不会主动闲逛。新任务优先于闲逛。
- 加宽书墙位于后方靠右，与办公室右侧边缘平行，正面朝室内。

### 对话与历史

侧边栏点击“新建对话”创建独立会话，办公室折叠，主区域显示消息及对应 Agent 头像。支持选择伙伴、Enter 发送、Shift+Enter 换行。第一条消息自动成为会话标题；侧边栏历史可恢复消息和草稿，点击“返回办公室”展开场景。

### 本地知识库与取书

1. 点击书墙标签或侧边栏“知识书墙”。
2. 添加文本资料，或导入 TXT / Markdown。
3. 在知识区选择 Agent 并输入检索问题；也可在对话中勾选“调用图书墙知识区”。
4. 命中资料后，对应 Agent 沿过道去书墙取书，携书返回工位。结果包含书名、原文片段和来源偏移；对话调用的结果会保存到该会话。

当前知识检索采用本地关键词匹配，按 480 字符分段、360 字符步长检索。单份资料最多 10 万字符，导入文件限制为 400KB。没有命中时不会播放取书动画。

### 知乎网页窗口

点击“本地知识库 → 知乎网页”，右侧打开知乎风格窗口。展开“网页设置”填写标题、HTTPS 知乎网址及可选正文。支持搜索保存的标题及正文、阅读全文、返回列表、打开原文和移除网页。

只有添加了正文的网页参与知识检索。仅保存 URL 时作为书签，不自动抓取网页，也不代表已读取远程内容。

### 其他侧边栏功能

- **自动任务**：创建每日任务，可启用、暂停、删除或立即交代。定时触发需要保持页面打开；Agent 忙碌时不覆盖原任务。
- **技能广场**：把资料整理、流程规划、文件归档模板交给对应伙伴。
- **应用**：打开工作空间内的工具。
- **文档 / 图库 / 此电脑**：选择本地文件并预览文本或图片，不会扫描磁盘。
- **设置**：调整动画速度和播放状态。
- **通知**：查看本次会话中的任务记录。

## 数据与功能边界

| 数据 | 保存位置 | 刷新后 |
| --- | --- | --- |
| 新版对话消息 | 后端数据库，浏览器镜像缓存 | 保留 |
| 草稿、旧版演示对话 | 当前浏览器 localStorage | 保留 |
| 知识资料、知乎链接与正文 | 当前浏览器 localStorage | 保留 |
| 自动任务配置 | 当前浏览器 localStorage | 保留 |
| 办公室任务状态、临时文件预览 | 内存 | 清除 |

清除网站数据会移除本地保存的资料；知识墙和草稿在不同浏览器或端口之间不共享。后端对话仍可在连接同一后端后恢复。隐私模式或存储空间不足时可能只能在当前会话内保存。

聊天与技能表单已接后端运行、状态流、历史和引用。云模式使用后端模型；显式联调模式使用确定性回答。Token 为界面估算，定时任务与办公室手动操作仍为本地演示，不在关闭网页后后台执行。真实云端调用需配置并验收。

## 常见问题

- **`vite: not found`**：先在项目根目录执行 `npm install`。
- **安装提示 `EAI_AGAIN`**：检查当前终端的网络、DNS 及 npm 仓库访问。
- **场景空白或提示 WebGL 不可用**：更新浏览器，启用硬件加速并刷新页面。
- **写文件时报 `Read-only file system`**：检查开发工具的工作区挂载权限；修改文件权限无法修复只读挂载。
- **找不到历史对话**：确认使用相同浏览器和相同地址端口，且没有清除网站数据。

## 合并后的前后端边界

唯一前端为根目录 `index.html`、`src/` 和 `vite.config.js`（知乎 / Three.js）。拉取仓库中的 Next.js / React 前端 `apps/web/` 已移除，根目录 npm 命令只运行知乎前端，不再使用 npm workspaces。

拉取的 FastAPI 后端 `apps/api/`、数据库配置 `infra/` 和相关脚本保留。后端安装与启动见 [本地配置说明](docs/local-setup.md)。当前知乎前端已连接后端聊天、技能提交、运行状态、取消、重试、历史与引用。知识墙仍在本地保存，选中的节选可通过会话附件传给后端；AI 分区可单独调用后端。完整启动见最小框架说明。不要将后端 API_TOKEN、模型密钥或数据库密码放入前端的 VITE 环境变量。

仓库中的 DESIGN.md、PRODUCT.md、UX-CONTRACT.md 及部分 PRD / 验收记录为拉取后端时附带的历史材料，不代表当前知乎界面的实现状态。
